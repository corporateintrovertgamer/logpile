# Brag Plan: Logpile (Official In-App Edition)

## What is this app?
Logpile is a hyper-fast, privacy-first, cinematic PC game library manager and launcher that unifies fragmented storefronts (Steam, Epic, GOG, emulators, standalone installs) into a single 4K desktop sanctuary with zero ads, automated SteamGridDB scraping, and 100% offline SQLite data sovereignty.

## The angle
"Tired of game launchers feeling like digital shopping malls jammed with microtransaction ads and 15-second load times? Logpile is the collector's sanctuary." We show the real, running client: 87 games unified, the Death Stranding Director's Cut cinematic hero view, Today's Pick local randomizer, and storefront filtering.

## Real In-App Assets Used
- **Brand Hero Banner:** 3D glass logo + "LOGPILE: Offline-First Game Library Manager for Windows"
- **Main Library Grid (`All games`):** 87 titles unified across Steam, GOG, Epic, Ubisoft, EA (A Plague Tale, Assassin's Creed series).
- **Cinematic Game Detail View:** Death Stranding Director's Cut (Kojima Productions art, Play Now split button, metadata specs).
- **Today's Pick:** Private roulette wheel for backlog paralysis.
- **Storefront Source Filtering:** GOG filter with Prince of Persia & The Witcher series.
